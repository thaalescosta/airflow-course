Exercise

Requirement

One sentence. What the learner builds, in the terms of the thing being built. No code here: this is a specification, and the learner writes the code.

Input
What exists before the learner starts: the branch state, the files already written, the data in the warehouse.
Output
What exists afterwards, stated as an artifact: a module at a path, a model that materialises, a state you can observe.
Interface surface
The API the learner is allowed to reach for — the signatures, the decorators, the CLI verbs, with the pinned versions from RESOURCES.md. Name the surface; do not demonstrate it.
Constraints
  • No code to copy. The worked example above is referenceable, not transcribable.
  • Nothing added to the project that a later lesson would have to undo.
  • Verified at the pipeline seam: the thing is correct when the pipeline says it is, over a re-run and over a backfill.
