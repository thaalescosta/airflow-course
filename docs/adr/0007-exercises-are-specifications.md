# Exercises are specifications, not code to copy

Exercises give a requirement, the relevant API surface, and a worked example elsewhere in the project. The learner writes the code. Follow-along is reserved for container setup and mechanical syntax that has no reason to be remembered.

This is the deliberate opposite of the foil, which types every line with the viewer and ends with the feeling of understanding rather than its structure. Because the course is one continuous project, every task is met again later, so copying it has no value. It also means the repository is a genuine portfolio artifact rather than a tutorial someone else wrote — a reader of the repo sees a pipeline someone designed.

A worked example deliberately placed *elsewhere* matters: it is referenceable when stuck without being a transcription target.
