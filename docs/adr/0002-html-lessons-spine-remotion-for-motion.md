# HTML lessons are the spine; Remotion renders only what must move

Lessons are self-contained, Tufte-style HTML documents under `lessons/`, cross-linked by anchor and sharing one stylesheet in `assets/`. Remotion lives in `motion/` and renders short clips embedded in those lessons, invoked only where motion is the only way to show the thing: dependency resolution, task-state transitions, the scheduler hand-off, task fan-out. A video course was rejected — every content change forces a re-render, text baked into frames cannot be searched or corrected without one, and hours of continuous video is the wrong unit for a learner whose working memory is the scarce resource. The short-lesson constraint is a pedagogical one: it forces decomposition of the source material, which is most of the value here.
